# SEED NOTE — read before using the template

This template was seeded from a real repository (3 apps, ~37k lines). Every number,
path, frame name and test count in `example/` is a concrete example from that seed
repo — NOT a general standard. The `template/` itself ships with `MEASURE`
placeholders instead of numbers.

**Required after init:**
1. Measure the real test/line counts of your project → update TESTING_GUIDE §1,
   AGENTS.md Quick Facts, and the MODULE_MAP/FRONTEND_MAP tables
2. Read every `docs/ai-context` file — delete/replace content that does not match
   your domain
3. Skills ARE bundled by default in `.claude/skills/` (95 dirs from the seed corpus,
   pool: `skills-disabled/` 13 dirs) — triage per YOUR stack (move folders between the
   two, delete what you never need) and record every source in `SKILL-SOURCES.md`;
   `init --no-skills` skips the bundle entirely
4. `scripts/verify.mjs` + `doc-truth.mjs` are CONFIG-DRIVEN: they read gates/claims
   from `kit.config.json` (a starter with empty arrays is generated by init) — fill
   `apps`, `gates`, `claims` per `kit.config.schema.json`, then run
   `node scripts/verify.mjs --list`
