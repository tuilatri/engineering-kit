# Triage Label Vocabulary

> Minimal label set for the local-markdown tracker mode (see
> `issue-tracker-local.md`). The `triage` skill can stay DISABLED for a private
> repo / solo dev — there is no external issue stream to triage. Keep this file
> to re-enable it once the repo has multiple people or public issues.

| Label | Meaning |
|---|---|
| `bug` | Broken behavior, fix now |
| `feature` | New capability |
| `chore` | Maintenance, no behavior change |
| `docs` | Documentation-only change |
| `wontfix` | Considered and rejected — do not revisit |
