# Glossary — BooK_Collection_Management

> Ubiquitous language for the domain (P12-3, seeded by domain-modeling discipline).
> Add terms as the domain model sharpens; keep definitions ≤ 2 lines.

| Term | Definition |
|---|---|
| Series (bộ) | A group of volumes belonging to one work; completion = all volumes owned |
| Volume (tập) | A single purchasable unit of a series |
| Bookmark (tác phẩm) | A standalone literary item tracked independently of series |
| Accessory (phụ kiện) | Collectible merchandise: standee, acrylic, keychain, shikishi... |
| Missing volume | A volume of an owned series that is not yet owned |
| Cozy map | The 2D PixiJS top-down study-room visualization (3 rooms A/B/C) |
| Detail rig | One detail = one folder under `frontend/src/lib/workspace/details/` — painter spec + rig + test |
| Sparkle | Daily hidden collectible in the cozy map (3/day, seeded by date) |
