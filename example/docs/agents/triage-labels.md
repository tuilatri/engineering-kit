# Triage Label Vocabulary

> P12-3: minimal set for local-markdown mode. The `triage` skill itself is
> DISABLED (solo dev, no external issue flow) — kept here for completeness if
> the triage skill is re-enabled later.

| Label | Meaning |
|---|---|
| `bug` | Broken behavior, fix now |
| `feature` | New capability |
| `chore` | Maintenance, no behavior change |
| `docs` | Documentation-only change |
| `wontfix` | Considered and rejected — do not revisit |
